## Several accounts, one status bar

Claude Multi Session does not sign you in — Claude Code does that. Claude Multi Session keeps a
copy of each sign-in once it exists, so you can move between them.

**Add another account** does this:

1. Saves the account you are on now.
2. Signs Claude Code out.
3. Waits while you sign in with the other account.
4. Saves that one too.

After that, clicking the status bar lists every account with its own figures,
and choosing one swaps the sign-in and brings your sessions back on it.

Already signed in somewhere else? **Save the Current Login** captures whatever
Claude Code is holding right now, without signing out of anything.
